# ST Bank
Telegram-бот с механикой трейдинга в реальном времени

[![CodeFactor](https://www.codefactor.io/repository/github/zenqst/st-bank/badge)](https://www.codefactor.io/repository/github/zenqst/st-bank)

### Стек
| Задача | Технология |
|--|--|
| API для работы с TG | aiogram |
| База данных | PostgreSQL |
| Развёртывание | Docker |
| Работа с сервером | Flask |
| Типизация | pydantic |
